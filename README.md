# YUMRYIT — GitHub Pages website

Upload the contents of this folder to the GitHub Pages repository for `https://frenlydev.github.io/yumryit/`.

The site is a static HTML/CSS/JS build with all visual assets stored in `assets/`.

Designed for mobile-first viewing with a compact navigation menu, responsive image layouts, readable typography, touch-friendly controls, an expandable FAQ, and a persistent WhatsApp order button on small screens.
